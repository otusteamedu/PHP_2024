ER-диаграмма

    Кинотеатр (Theater)

        id — уникальный идентификатор кинотеатра.

        name — название кинотеатра.

        address — адрес кинотеатра.

    Зал (Hall)

        id — уникальный идентификатор зала.

        theater_id — ссылка на кинотеатр.

        name — название зала.

        capacity — вместимость зала.

    Тип места (SeatType)

        id — уникальный идентификатор типа.

        name — название типа (обычное, VIP и т.д.).

    Место (Seat)

        id — уникальный идентификатор места.

        hall_id — ссылка на зал.

        type_id — ссылка на тип места.

        row_number — номер ряда.

        col_number — номер места в ряду.

    Фильм (Movie)

        id — уникальный идентификатор фильма.

        title — название фильма.

        description — описание фильма.

        duration — продолжительность фильма.

        rating — возрастной рейтинг.

    Сеанс (Session)

        id — уникальный идентификатор сеанса.

        movie_id — ссылка на фильм.

        hall_id — ссылка на зал.

        start_time — время начала сеанса.

        end_time — время окончания сеанса.

    Цена (Price)

        id — уникальный идентификатор цены.

        session_id — ссылка на сеанс.

        type_id — ссылка на тип места.

        price — стоимость билета для данного типа места на данном сеансе.

    Билет (Ticket)

        id — уникальный идентификатор билета.

        price_id — ссылка на цену.

        sold_at — дата и время продажи билета.
