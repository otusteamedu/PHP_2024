## Решение

### Краткое описание
Маппинг структуры хранения находится в виде JSON файле mapping.json. При любом обращении к сервису происходит проверка существования индекса, и если индекс не существует, он создается.
Для решения задачи было решено использовать один индекс и одну структуру для хранения информации.
Для выборки данных используются возможности агрегирования данных в запросах Elasticsearch.

### Реализация
Решение выполнено в виде сервиса, принимающего два query-параметра: command и data.
Для удобства проверки через браузер все запросы реализованы через метод GET.

В command передается действие, которое необходимо выполнить:
* add - добавить видео (структура видео передается в параметре data в виде json-строки)
* delete - удалить видео по его id (id видео передается в параметре data в виде json-строки)
* channel_summary - получить cуммарное кол-во лайков и дизлайков для канала по всем его видео (имя канала передается в параметре data в виде json-строки)
* top_channels - получить топ N каналов с лучшим соотношением кол-во лайков/кол-во дизлайков (количество передается в параметре data в виде json-строки)
* _seed - первоначальное заполнение индекса тестовыми данными (данные находятся в файле seed_data.json)
* _storage_info - информация об Elasticsearch

### Установка
1. Склонировать себе сервис (git clone)
2. Запустить контейнеры (docker-compose up -d --build)
3. Сделать привязку в файле hosts домена mysite.local к 127.0.0.1

Дальнейшие команды выполняются внутри контейнера php-fpm.
4. Зайти внутрь контейнера (docker-compose exec php-fpm bash)
5. Установить библиотеки composer (composer install)


### Примеры запросов
- добавление

http://mysite.local?command=add&data={"channel": "О природе", "title": "Животные Африки", "release_date": "2002-01-15", "likes": 3, "dislikes": 10}

- удаление

http://mysite.local?command=delete&data={"id": "rXxI5pUBzDoxP0r7RjKs" }

- cуммарное кол-во лайков и дизлайков для канала по всем его видео

http://mysite.local?command=channel_summary&data={"channel": "Кулинария"}

- топ N каналов с лучшим соотношением кол-во лайков/кол-во дизлайков

http://mysite.local?command=top_channels&data={"limit": "3"}

- первоначальное заполнение индекса тестовыми данными

http://mysite.local?command=_seed

- информация об Elasticsearch

http://mysite.local?command=_storage_info
