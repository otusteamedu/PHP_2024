# Домашнее задание №12  
## Паттерны работы с данными
### Цель:
Научиться применять на практике востребованные паттерны работы с хранилищами.

### Описание/Пошаговая инструкция выполнения домашнего задания:

Необходимо реализовать один из паттернов: Table Data Gateway, Raw Data Gateway, Active Record, DataMapper для произвольной таблицы.

Паттерн должен содержать метод массового получения информации из таблицы, результат которого возвращается в виде коллекции.

Дополнительно можно использовать паттерн Identity Map для устранения дублирования объектов, ссылающихся на одну строку в БД или Lazy Load для отложенной загрузки связанных записей в таблице или коллекции.

### Критерии оценки:
Основная задача - реализация одного из перечисленных паттернов на произвольной таблице.
Желательно реализовать метод массового получения информации.
Желательно реализовать один из паттернов: Identity Map или Lazy Load.

## Решение

Реализован паттерн DataMapper (для сущности Car) и дополнительный паттерн LazyLoad (свойство сущности Car: driver - водитель)
Описания сущностей находятся в папке Entity, DTO для создания сущностей в папке DTO, мапперы в папке Mapper. 
Для реализации Lazy load создан класс DriverProxy (наследник от Driver).
Для проверки создан класс TestDataMapper, в котором производятся все основные действия над сущностями.

### Установка
1. Склонировать себе сервис (git clone)
2. Запустить контейнеры (docker-compose up -d --build)

Дальнейшие команды выполняются внутри контейнера php-fpm.
3. Зайти внутрь контейнера (docker-compose exec php-fpm bash)
4. Установить библиотеки composer (composer install)

Для создания БД и таблиц необходимо выполнить скрипт create_db.sql.

### Запуск и тестирование
Для проверки создан класс TestDataMapper, вызов которого осуществляется из файла test.php.
Для запуска необходимо внутри контейнера выполнить команду "php test.php". 
Вывод тестовой информации производится в консоль.
