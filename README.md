### 1. Решение задачи на поиск циклов в списке
Для решения использовал алгоритм Флойда поиска цикла (он же алгоритм «черепахи и зайца»)
#### 1.1. Оценка сложности алгоритма 
Сложность алгоритма Флойда известна, она равна O(n) по количеству операций и О(1) по памяти.

### 2. Решение задачи с генерацией комбинаций символов из телефонных номеров
Использован рекурсивный алгоритм, берутся все варианты букв для первой цифры строки номера, 
и к каждому из них добавляются "хвосты", сформированные из оставшейся строки.

#### 2.1. Оценка сложности алгоритма
Сложность алгоритма между О(3^n) и O(4^n) (где n - количество цифр в изначальном номере), 
т.к. осуществляется полный перебор всех комбинаций букв по каждой цифре (3 или 4 буквы) n раз
