# Домашнее задание №17  
## Пишем тесты
### Цель:
Научиться реализовывать юнит-тесты на практике

### Описание/Пошаговая инструкция выполнения домашнего задания:

Возьмите свое приложение "Чат на сокетах"
Покройте юнит-тестами его код
Покрытие тестами должно иметь минимальный уровень в 65%
Какие еще тесты из пирамиды тестирования могут тут быть полезными? Вы можете их реализовать?

## Решение
В виду отсутствия приложения "Чат на сокетах" за основу взято приложение из ДЗ №20 - REST API с использованием очередей.
Данный проект реализован в рамках чистой архитектуры на основе фреймворка Laravel 11.

Для юнит-тестирования использованы PHPUnit и библиотека Mockery, которая делает написание тестов в Laravel более удобным по сравнению с чистым PHPUnit. 
Созданы unit-тесты для UseCase и репозитория, и один интеграционный для класса контроллера. 

Покрытие тестами измерено с помощью дополнительной библиотеки _phpunit/php-code-coverage_, и составляет относительно строк кода 69%. 
Результат измерения покрытия приложен в виде скриншота в файле _phpunit-coverage.png_

### Запуск тестов
- Запуск тестов осуществляется командой **./vendor/bin/phpunit**
- Измерение покрытия командой **./vendor/bin/phpunit --coverage-html coverage-report tests**


### Установка сервиса
1. Склонировать себе сервис (git clone)
2. Запустить контейнеры (docker-compose up -d --build)
3. Сделать привязку в файле hosts домена mysite.local к 127.0.0.1
   Дальнейшие команды выполняются внутри контейнера php-fpm.
4. Зайти внутрь контейнера (docker-compose exec php-fpm bash)
5. Установить библиотеки composer (composer install)
6. Создать и заполнить файл .env (лучше просто сделать копию с файла env.example)
7. Обновить конфигурацию (php artisan optimize)
8. Запустить миграцию для создания БД и таблицы (php artisan migrate)


### Примеры запросов

#### Создание заявки 
    POST http://mysite.local/api/v1/leads/
    {
        "userName": "Иванов Петр",
        "email": "test@testemail.ru",
        "body": "Какая-то информация по заявке"
    }

Ответ:

    {
        "id": 7
    }

#### Получить статус заявки
    GET http://mysite.local/api/v1/leads/7/status

Ответ:

    {
        "status": "queued"
    }

#### Получить результат выполнения заявки
    GET http://mysite.local/api/v1/leads/7/result

Ответ:

    {
        "result": {
            "sum": 718,
            "status": "success",
            "message": "Заявка 7 успешно обработана!"
        }
    }
