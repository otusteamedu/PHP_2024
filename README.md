# Домашнее задание №21  
## Скрипт деплоя
### Цель:
Научиться доставлять приложение до указанной среды

### Описание/Пошаговая инструкция выполнения домашнего задания:

Используя выбранный инструмент автоматического деплоя, необходимо реализовать автоматическую выкатку написанного ранее мини-приложения на собственный виртуальный сервер.

### Критерии оценки:
- Автоматическая доставка на любую среду;
- Доставка без downtime;
- Желательно организовать отдельный закрытый репозиторий настроек, из которого формируются файлы конфигурации для выбранной среды в момент деплоя.

## Решение
В качестве проекта для деплоя взято приложение из ДЗ №17 (оно же ДЗ№20, но с тестами) - REST API с использованием очередей.
В качестве инструмента деплоя выбран Gitlab, ссылка на проект https://gitlab.com/sergey-shirykalov/otus-2025-hw21-async-bank.

Конфигурация nginx для удаленного сервера находится в файле deploy/nginx.conf.
Скрипт деплоя - файл deploy.sh, вызывается из .gitlab-ci.yml.
Адрес сервера для развертывания, на котором можно проверить развернутую систему - 80.87.106.175.

В скрипт деплоя помимо непосредственно развертывания включен запуск юнит-тестов. 

Cкриншоты этапов настройки, деплоя и работы развернутого сервера находятся в папке deploy_screenshots. 
В случае необходимости могу предоставить дополнительную информацию или скриншоты. 

### Примеры запросов на виртуальном сервере

#### Создание заявки 
    POST http://80.87.106.175/api/v1/leads/
    {
        "userName": "Иванов Петр",
        "email": "test@testemail.ru",
        "body": "Какая-то информация по заявке"
    }

Ответ:

    {
        "id": 7
    }

#### Получить статус заявки
    GET http://80.87.106.175/api/v1/leads/7/status

Ответ:

    {
        "status": "queued"
    }

#### Получить результат выполнения заявки
    GET http://80.87.106.175/api/v1/leads/7/result

Ответ:

    {
        "result": {
            "sum": 718,
            "status": "success",
            "message": "Заявка 7 успешно обработана!"
        }
    }
