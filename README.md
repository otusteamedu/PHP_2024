### 4. Convert binary number in a linked list to integer
#### 4.1 Рекурсивное решение
Производится последовательный обход списка, на каждом шаге определяется позиция текущего бита во всем числе (через рекурсивное определение длины списка) и он добавляется к результату, умноженный на соответственную степень двойки.
#### 4.1.1 Оценка сложности рекурсивного алгоритма
Сложность алгоритма равна O(N^2), т.к. в каждом вызове метода getDecimalValue (который вызывается N раз) происходит еще вызов метода getDepth, который также вызывается N раз.
#### 4.2 Решение без рекурсии
Список перебирается в цикле, в каждой итерации текущее значение узла прибавляется к уже полученному результату, сдвинутому влево на 1 бит
#### 4.2.1 Оценка сложности нерекурсивного алгоритма
Сложность алгоритма равна O(N), т.к. имеем только один обход списка в цикле.
