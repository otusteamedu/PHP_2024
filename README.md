**Консольное приложение рекурсивно выводит список каталогов и файлов начиная с заданного каталога.**
- каталоги и файлы отображаются в виде дерева
- по каждому файлу и каталогу выводится размер в kb
- если файл или каталог занимает больше 100 Kb, то не выводится
- для текстовых файлов (формат .txt) опционально выводятся первые 50 символов содержимого
- для HTML-файлов (формат .html) опционально выводятся первые 50 символов текста (удаляя теги)

**Работа с приложением**

`php Application.php + парметры`

**Параметры** 

`--path` - Корневой каталог. Обязательный. Тип значения - строка 

`--txt` - Выводить ли содержимое файлов формата .txt. Необязательный. 1 - да, отсутствие параметра или любое другое значение - нет

`--html` - Выводить ли содержимое файлов формата .html. Необязательный. 1 - да, отсутствие параметра или любое другое значение - нет

Пример использования

`php Application.php --path='./testFolder' --txt=1 --html=1`
